API эндпоинты для работы с событиями

  • GET /api/event — все события
  • GET /api/event/{id} — событие по ID
  • POST /api/event — создать (с валидацией)
  • PUT /api/event/{id} — обновить
  • DELETE /api/event/{id} — удалить
  • GET /api/event/future — только будущие события
  • GET /api/event/search/{name} — поиск по названию
