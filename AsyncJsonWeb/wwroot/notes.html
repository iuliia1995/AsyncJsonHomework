API эндпоинты для работы с заметками

  • GET /api/note — все заметки
  • GET /api/note/{id} — заметка по ID
  • POST /api/note — создать
  • PUT /api/note/{id} — обновить
  • DELETE /api/note/{id} — удалить
  • GET /api/note/owner/{ownerId} — заметки владельца
  • DELETE /api/note/owner/{ownerId} — удалить заметки владельца
